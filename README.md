# HAaddons

Home-Assistant-Add-on-Repository.

[![Repository hinzufügen](https://my.home-assistant.io/badges/supervisor_add_addon_repository.svg)](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2FDevilwitha%2FHAaddons)

## Add-ons

### [Claude Code](claude_code/)
Claude Code direkt auf HAOS, mit Web-Terminal in der Seitenleiste und Remote Control
über die Claude App oder claude.ai/code. Damit legst du Automationen an und änderst die
Konfiguration, ohne am Rechner zu sitzen. Details: [DOCS.md](claude_code/DOCS.md)

## Installation
Einstellungen → Add-ons → Add-on Store → ⋮ → Repositories →
`https://github.com/Devilwitha/HAaddons` hinzufügen.
